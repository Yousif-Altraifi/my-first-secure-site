# Phishing Detector
A simple & secure phishing link detection tool by Yousif Altraifi - Cybersecurity Student from Sudan

## About
This project helps detect phishing URLs using heuristic analysis and helps users stay safe online.

## Features
- URL validation and analysis
- Detects suspicious patterns
- Lightweight and fast
- Privacy focused

## Tech Stack
- Node.js
- JavaScript

## Installation
git clone https://github.com/Yousif-Altraifi/my-first-secure-site.git
cd my-first-secure-site
npm install
